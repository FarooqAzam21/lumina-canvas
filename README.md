# Lumina Canvas

Create a **world-class, highly creative, immersive 3D website** using **React + Vite + JavaScript JSX**.

The goal is NOT to create a normal website with a few 3D elements.

Create an **award-winning digital experience** that feels like it was designed by a top-tier creative technology studio.

The website should look:

* Futuristic
* Premium
* Cinematic
* Sophisticated
* Experimental
* Immersive
* Modern
* Minimal
* Extremely polished

Think of the quality level of premium Awwwards-winning websites, Apple product experiences, high-end creative agencies, and futuristic technology brands.

Do NOT make it look like a template.

---

# TECH STACK

Use:

* React
* Vite
* JavaScript JSX ONLY
* Tailwind CSS
* Framer Motion
* GSAP
* Three.js
* React Three Fiber
* @react-three/drei
* Lenis Smooth Scroll
* React Router / TanStack Router depending on the existing project

Use JavaScript/JSX, NOT TypeScript.

Create reusable components and a scalable architecture.

---

# HERO EXPERIENCE

Create an unforgettable fullscreen hero.

Instead of a conventional static hero image, create an interactive 3D environment.

Possible visual concept:

A floating futuristic object/product in the center of the screen.

* Floating particles
* Atmospheric fog
* Soft volumetric light
* Glass objects
* Abstract geometric shapes
* Floating typography
* Subtle reflections
* Dynamic shadows

The camera should slowly move.

The object should react to the mouse.

On mouse movement:

* Camera subtly follows cursor
* Object rotates
* Lighting shifts
* Particles react

Headline should appear through a cinematic text reveal.

Example:

**"CREATE BEYOND LIMITS."**

Subheading:

"Experience a new generation of digital design."

CTA:

**EXPLORE EXPERIENCE**

Secondary CTA:

**DISCOVER MORE**

# PERFORMANCE

This is extremely important.

Target:

90+ Lighthouse performance.

Use:

Lazy-loaded 3D scenes

Dynamic imports

Suspense

Compressed textures

Optimized models

requestAnimationFrame optimization

Avoid unnecessary React re-renders

Do NOT sacrifice performance for unnecessary visual effects.
